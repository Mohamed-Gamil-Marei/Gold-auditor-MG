# مراجع الذهب — نسخة سطح المكتب لويندوز (Electron)

نظام محلي متكامل للإدخال السريع ومراجعة حسابات محلات الذهب واكتشاف الشواذ المحاسبية وتسوية الخزنة والجرد اليومي. يعمل بالكامل **أوفلاين** بدون إنترنت (باستثناء ميزة قراءة صور الدفتر الاختيارية عبر Gemini).

---

## 1) التشغيل في وضع التطوير (Development)

1. تأكد من تثبيت **Node.js LTS** (الإصدار 20 أو أحدث) على جهازك.
2. افتح موجه الأوامر (Terminal / PowerShell) داخل مجلد المشروع ونفّذ:
   ```bash
   npm install
   ```
3. لتشغيل الواجهة والخادم المحلي للمعاينة السريعة:
   ```bash
   npm run dev
   ```
4. لتشغيل نسخة سطح المكتب (Electron) في وضع التطوير:
   ```bash
   npx electron .
   ```

---

## 2) بناء ملف التثبيت لويندوز (`.exe` Installer)

لبناء برنامج التثبيت النهائي لويندوز (`NSIS Installer`):

1. ثبّت حزم البناء الخاصة بـ Electron (إن لم تكن مثبّتة):
   ```bash
   npm install --save-dev electron electron-builder
   ```
2. ولّد أيقونات البرنامج (`build/icon.png` و `build/icon.ico`) وابنِ ملف التثبيت:
   ```bash
   npm run dist
   ```
3. ستجد ملف التثبيت الجاهز `.exe` داخل مجلد:
   ```text
   release/مراجع الذهب Setup 2.0.0.exe
   ```

---

## 3) التثبيت على جهاز ويندوز

- شغّل ملف التثبيت `.exe` الناتج في مجلد `release/`.
- لا يتطلب التثبيت صلاحيات مسؤول (Admin)، ويمكنك اختيار مجلد التثبيت.
- ينشئ المثبّت اختصاراً باسم **"مراجع الذهب"** على سطح المكتب وفي قائمة ابدأ.

---

## 4) أين تُحفظ البيانات والنسخ الاحتياطية؟

يحفظ البرنامج جميع بياناتك محلياً على جهازك داخل مجلد بيانات المستخدم:

```text
C:\Users\<اسم_المستخدم>\AppData\Roaming\مراجع الذهب\GoldAudit\
```
(أو داخل مجلد `GoldAuditData/` بجوار التطبيق في وضع الخادم المحلي).

ويحتوي هذا المجلد على:
- `data/state.json`: ملف البيانات الرئيسي (العمليات، الأيام، الأشخاص، العمال، السجل، الإعدادات) ويُكتب بطريقة ذرّية آمنة ضد انقطاع الكهرباء (`state.json.tmp` ← `fsync` ← `state.json`).
- `data/state.json.bak`: آخر نسخة سليمة قبل آخر كتابة مباشرة.
- `data/images/<YYYY-MM-DD>.jpg`: صور صفحات الدفتر المرفقة بالأيام.
- `data/security.json`: إعداد قفل البرنامج بكلمة مرور مشفرة (`scrypt + salt`).
- `data/gemini_key.enc`: مفتاح Gemini مشفراً بواسطة `safeStorage`.
- `backups/`: النسخ الاحتياطية التلقائية (يحتفظ بآخر 30 نسخة يومية وآخر 12 نسخة شهرية).

> يمكنك الوصول لهذا المجلد مباشرة من داخل البرنامج عبر: **الإعدادات ← فتح مجلد البيانات**.

---

## 5) نقل البيانات إلى جهاز كمبيوتر آخر

يمكنك نقل بياناتك بالكامل إلى جهاز جديد بإحدى طريقتين:

1. **الطريقة الأولى (نقل المجلد الكامل بالصور والنسخ):**
   - افتح **الإعدادات ← فتح مجلد البيانات** على الجهاز القديم.
   - انسخ مجلد `GoldAudit` بالكامل على فلاشة، والصقه في نفس المسار على الجهاز الجديد.

2. **الطريقة الثانية (ملف نسخة احتياطية JSON):**
   - من الجهاز القديم: افتح **الإعدادات ← تصدير نسخة احتياطية (JSON)**.
   - من الجهاز الجديد: افتح **الإعدادات ← استعادة من ملف JSON** واختر الملف.
